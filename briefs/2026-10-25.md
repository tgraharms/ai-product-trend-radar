## COMMUNITY
[8] Switch 2 gets its first software jailbreak, built with help from OpenAI's Codex
Researcher Sammy Hajhamid ("pepsipu") built an exploit called ns2jb with help from OpenAI's Codex and released it on October 22 for firmware 23.0.1. It runs arbitrary native code without a hardware modchip, which opens the door to homebrew, reverse engineering, game modding and save backups. It is tethered, so it does not survive a reboot. Nintendo appears to have pulled SmileBASIC 4, the game the exploit relies on, from the eShop, but has not officially responded. The story shows AI agents shortening the time needed to crack locked-down hardware. Nintendo's usual response is to patch and delist.
