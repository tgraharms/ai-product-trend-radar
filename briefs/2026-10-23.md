[10] Anthropic launches Claude Duet, a proactive always-on agent
Anthropic has launched Claude Duet, a proactive agent that handles tasks even when the user is offline. It runs on Claude Opus 5.5 and connects to Gmail, Slack and Stripe through more than 6,000 connectors. [8] REA, an AI reverse-engineering toolkit, explodes on GitHub
REA ("Reverse Engineer Anything") is an MIT-licensed project that hands the work of inspecting compiled apps to a coding agent. It reached 327,000 GitHub stars as of October 19, up about 200,000 in a week. It doesn't return original source code. It produces pseudocode, assembly and module relationships. Shipped desktop and mobile apps are now easier to study than before. Software makers should expect more copying of their features and may respond with legal or technical countermeasures.
